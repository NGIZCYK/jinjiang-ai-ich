## 运营洞察

- “用户行为”使用当前 Supabase 批次的实际记录；“经营推演”使用 Python 合成情景样本及可调假设。
- pandas 标准化和 KMeans 保持；`family-leisure` 内部 ID 保留，名称改为“休闲探索型 / Leisure explorers”，不声称存在家庭身份依据。
- 三个方案同屏比较预计参与、容量、增量收入、月度贡献、首年净 ROI 和回本时间。
- 可分别调整各方案参数；套餐单价与住客页面单项体验价格明确分开。
- 显示单客贡献、固定成本、材料成本、保本参与人数；零投入或无法回本显示“—”，不显示无穷值。
- 转化率、材料成本分别上下浮动 20%，一次只改一个因素；提示容量封顶导致的转化敏感性变平。
- 推荐措辞为“优先比较”，保留验证行动；删除旧的四周运营扩张门槛及未使用的判断函数。
- 分群可直接传入工作台，默认大堂展牌和 90 分钟。
- CSV 导出包含时间、当前批次漏斗及转化分母、参数、三方案结果与敏感性结果。批次未加载完时禁止导出，避免缺少分母的证据文件。
- 导出只含聚合信息，规避电子表格公式注入；不含反馈原文、聊天、联系方式或密码。
- AI 简报仅接收服务器聚合行为数据及方案摘要，不发送反馈原文；原有 JSON 响应结构保持兼容。

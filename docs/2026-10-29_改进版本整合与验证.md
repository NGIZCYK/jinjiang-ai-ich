## 本次额外处理

- 根目录 `.nvmrc` 与 Netlify `NODE_VERSION` 固定 Node 24.22.1，前端 engines 收窄到 `^24.22.1`。
- 测试、演示开发、演示构建及双击启动器检查 Node 版本，避免系统 PATH 中 Node 26 触发难以理解的存储环境错误。

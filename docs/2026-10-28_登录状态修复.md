# 登录状态修复（2026-10-28）

## 行为变化

- 登录会话仅保留在当前页面内存中。重新打开或刷新网站从未登录开始，不恢复浏览器中旧的运营账号会话；站内导航保留当前登录。
- 住客和运营快捷登录卡片继续保留，点击填入后由用户提交登录。
- 登录事件和显式登录共享身份加载过程，重复事件不再清空已加载身份；过期的排队事件不再覆盖新的登录状态。
- 退出时立即清理页面身份，资料加载失败时退出加载状态并显示错误。
- “我的行程”在身份清空时安全渲染，避免退出期间访问空用户对象导致页面崩溃。

## 本地验证

- 199 项前端测试全部通过，包含旧持久会话忽略、重复登录事件、退出后再次登录、退出期间未完成请求和资料请求失败的回归测试。
- TypeScript 检查、演示构建及演示产物检查通过。
- Edge 无界面浏览器验证：预置旧运营会话仍显示未登录；连续 5 次住客/运营登录退出；登录后刷新恢复未登录；未捕获页面异常为 0。
- 浏览器验证使用模拟 Supabase 响应，未修改线上账号或业务数据。这项验证覆盖页面登录状态流转，不代替真实后台可用性验收。

## 发布

前端更新经 GitHub main 分支触发 Netlify 构建；本次无数据库迁移或后台函数修改。

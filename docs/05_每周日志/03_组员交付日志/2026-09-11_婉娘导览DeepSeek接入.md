### 2. DeepSeek API 对话接入

涉及文件：

- `jinjiang-ai-ich/web/vite.config.ts`
- `jinjiang-ai-ich/web/src/lib/llm.ts`
- `jinjiang-ai-ich/web/.env.example`
- `jinjiang-ai-ich/.env.example`
- `jinjiang-ai-ich/web/.gitignore`
- `jinjiang-ai-ich/README.md`

实现内容：

- 在 Vite 本地服务中增加同源接口：`GET /api/chat/status` 与 `POST /api/chat`。
- 后端接口从服务端环境变量读取 `DEEPSEEK_API_KEY`，浏览器不会收到密钥；前端只请求同源 `/api/chat`。
- 默认使用 `deepseek-v4-flash`，并关闭思考模式，避免模型只输出思考过程而没有可展示回复。
- 前端能够显示当前是 `DeepSeek API` 还是本地演示回复；接口异常时会回退到本地回复并显示提示。
- 增加 `.env.example` 和 README 配置说明；真实密钥仅应保存在未提交的 `web/.env` 中。

### 3. 婉娘的语气和对话内容优化

涉及文件：

- `jinjiang-ai-ich/web/vite.config.ts`

实现内容：

- 将人设调整为“温婉礼宾为主、江南叙事为辅”。

### 4. 多轮对话与导览动作

涉及文件：

- `jinjiang-ai-ich/web/vite.config.ts`
- `jinjiang-ai-ich/web/src/lib/llm.ts`
- `jinjiang-ai-ich/web/src/pages/GuidePage.tsx`

实现内容：

- 前端会把已有聊天记录随新问题发送给 API，模型可理解“独自来”“四小时”“预算 500”等上下文。
- 为模型增加三个受控动作：生成体验行程、生成预约草稿、打开沉浸非遗角建议。
- 行程动作会在聊天区显示时间安排；预约动作只生成“尚未提交预约”的草稿；沉浸动作提供进入 `/immersive` 的链接。
- 动作参数会在本地校验，模型不能直接创建真实预约或执行未授权操作。

### 5. 避免重复表达

涉及文件：

- `jinjiang-ai-ich/web/vite.config.ts`

实现内容：

- 每次请求会额外传入最近三条婉娘回复，作为“已提及内容”。
- 提示词明确禁止在用户只补充同行人、时长、预算等信息时，反复使用“从劈丝看起”“绣一片花瓣”“八字要诀”等已经说过的内容。
- 实测同一段对话后，对“四小时、预算 500”的回复会推进为节奏、预算确认和偏好选择，不再重讲前文体验内容。

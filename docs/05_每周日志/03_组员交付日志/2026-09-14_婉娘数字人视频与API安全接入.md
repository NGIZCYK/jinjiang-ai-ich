## 4. 恢复 DeepSeek API 接入

涉及文件：

- `web/vite.config.ts`
- `web/src/lib/llm.ts`
- `web/src/pages/GuidePage.tsx`
- `web/src/vite-env.d.ts`
- `web/.env.example`
- `.env.example`
- `web/.gitignore`
- `README.md`

完成内容：

- 发现同学合并后的项目虽然有 DeepSeek 请求代码，但没有本机密钥文件，并且使用 `VITE_DEEPSEEK_API_KEY` 让密钥暴露在浏览器端。
- 改为安全的同源 API 方式：浏览器调用 `/api/chat`，Vite 本地服务使用 `DEEPSEEK_API_KEY` 调用 DeepSeek。
- 新增 `GET /api/chat/status`，用于页面识别当前是 `DeepSeek 联网生成` 还是本地演示回复。
- `/api/chat` 会携带用户问题、最近对话和相关苏绣资料；API 不可用时自动保留本地规则回复，避免课堂演示中断。
- 恢复温婉礼宾语气、素材约束和“避免重复前文工艺细节”的服务端提示词。
- 在页面加载时检查 API 状态，避免前端直接读取任何密钥。
- 更新 `.env.example`、`.gitignore` 和 README，说明安全配置方式。

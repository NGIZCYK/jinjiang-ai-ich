# 成员工作日志｜阶段四：全站可信体验、交互与功能逻辑重构

## 一、迭代目标

本轮不再增加孤立页面，而是在保留首页、婉娘导览、沉浸非遗角、内容工作台、我的体验、分析看板和登录注册等主要板块的前提下，统一全站美学语言并修正功能链路。

本次重点解决以下问题：

1. 页面虽然具备较多功能，但部分模块仍有通用 SaaS 工具感，移动端导航与信息层级不够稳定；
2. 婉娘导览无法准确说明当前使用 DeepSeek、离线知识库还是接口降级模式；
3. 工作台可以跳过人工核验直接进入分发，修改输入后旧审核状态仍可能继续生效；
4. 预约页面把课程原型写成真实库存、特惠价格、VIP 席位和防伪雅券，超出已有证据；
5. 分析看板把合成样本写成“实时运营指令”，容易把情景假设误读为真实经营结论；
6. 沉浸工坊中 2.6x、3x 显示不一致，劈丝微米值及部分针法表述缺乏可核查依据；
7. 英文版知识卡、审核状态和婉娘问候仍存在中文残留或标点排版问题；
8. 全站加载了当前页面已经不再使用的 A-Frame 脚本，增加首屏负担。

## 二、本轮完成内容

### 1. 全站视觉系统与响应式导航

- 延续米纸白、墨色、水碧和暖金色体系，统一卡片边框、柔和阴影、按钮状态和表单焦点反馈；
- 调整首页标题、正文、指标、轮播展签与内容卡的间距和字阶，强化“文化策展”而非普通后台的视觉感受；
- 为窄屏增加紧凑语言切换和账户操作，移动导航采用横向滚动与吸附定位；
- 增加“跳到主要内容”链接、统一键盘焦点样式和减少动态效果偏好支持；
- 优化首页轮播在手机端的展签和按钮布局，避免绝对定位元素扩大页面宽度。

### 2. 首页内容层级与真实性校正

- 明确核心用户为“在苏州停留一至两晚的文化旅行者”；
- 将首页三项核心能力重新表述为：婉娘知识导览、数字微距工坊、内容与运营；
- 保留五张苏绣风格数字作品轮播，但统一标注为“数字创作、非馆藏复制”；
- 删除未经确认的 ¥398、¥680、赠课、固定茶歇和装裱承诺；
- 改用“核心旅程”和“延伸旅程”说明产品原型及待确认边界。

### 3. 婉娘导览状态与中英文体验

- 修复 React StrictMode 下可能重复插入欢迎语的问题；
- 新增三项初始快捷入口：理解工艺、阅读文脉、规划停留，减少首次进入后的大面积空白；
- 明确显示三种回复状态：DeepSeek 联网生成、本地规则知识库、接口异常后的本地降级；
- 修复英文问候中的弯引号排版问题，改为稳定的 `Hello, I am Wanniang.`；
- 英文知识提示、预约引导和状态文案重新核对，减少中文残留；
- “帮我安排 2 小时体验”等问题会读取实际时长并动态生成分段，不再固定输出 90 分钟；
- 调整情感判断规则，避免把询问 `Why is it difficult?` 误判为负面情绪；
- 清空对话后会同步重置初始化状态，并重新生成单条当前语言欢迎语。

### 4. 沉浸非遗角交互与文化表述

- 将界面和算法中的放大倍率统一为 3x；
- 放大镜半径改为读取当前 DOM 实际尺寸，解决不同响应式尺寸下背景定位偏差；
- 支持点击、指针移动和触控定位，三大展区按钮增加选中状态语义；
- 将劈丝展示从未经证实的固定微米值改为整股、1/2、1/4、1/16、1/32 的相对粗细示意；
- 明确《姑苏繁华图》部分是参照公开著录进行的数字纹理演绎，不是馆藏绣品复制；
- 将针法判定、材料、师资、成品和场次统一标记为待传承人或合作工坊复核；
- 工坊终点 CTA 从“锁定付费席位”改为“记录 90 分钟体验意向”。

### 5. 内容工作台真实状态机

内容工作台继续使用四步结构，但补齐了步骤之间的约束：

1. 定义客群、渠道、情景与总时长；
2. 生成可编辑的规则辅助草稿；
3. 人工核对出处、工艺表述与服务可履约性；
4. 审核通过后才可进入客房信笺和大堂水牌预览并保存。

功能修正包括：

- 未审核内容无法进入第四步或保存；
- 修改客群、渠道、时长、情景、正文或审核意见后，旧审核状态自动失效；
- 60、90、120、180 分钟方案均按比例计算，四段时间之和严格等于输入总时长；
- 英文知识卡新增独立标题、摘要和来源说明，不再直接显示中文知识库字段；
- 分发预览删除固定房号、VIP、特惠价、固定库存和未确认服务承诺；
- 页面明确标注这是“规则辅助草稿”，人工审核不由系统自动代替。

### 6. 我的体验与本地鉴权

- 将“预约工坊席位”调整为“记录体验意向”，明确不含支付、不代表真实库存；
- 同一用户、同一时段已经存在有效意向时，阻止重复记录；
- 将 VIP Pass、防伪编码和“席位锁定”改为浏览器本地体验确认单；
- 确认单说明场次、容量、师资、材料和最终安排均待运营确认；
- 登录不再接受任意长度大于 6 位的密码；演示账号和新注册账号均进行本地密码比对；
- 新注册账号固定为住客角色，避免仅凭 `ops` 邮箱前缀获得运营身份；
- 登录页增加住客与运营演示账号一键填入，并明确本地鉴权不能用于生产环境。

### 7. 分析看板从“指令”改为“决策支持”

- 保留 KMeans 合成客群、收入指数和 ROI 情景；
- 删除“实时决策生效”“100% 来源考证”“附加率 +28%”等无法由当前数据证明的表达；
- 新增“输入—观察—决策门槛”结构，把情景结果转换为下一步实验建议；
- 根据基线、轻体验、主题房与工坊三种情景动态给出不同建议；
- 明确合成样本和浏览器本地意向记录不能替代锦江真实经营数据。

### 8. 性能与页面元信息

- 从 `index.html` 移除全站阻塞加载、当前代码已未使用的 A-Frame 脚本；
- 首页首张轮播图增加 preload 和高优先级加载；
- 增加页面 description 和主题色元信息；
- 保留旧 A-Frame 文件和历史全景资产，避免破坏此前迭代证据，但当前页面不再请求该脚本。

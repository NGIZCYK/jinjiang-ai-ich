# 成员工作日志｜婉娘导览与快捷启动稳定性优化

## 一、当日目标

在保留婉娘数字人、DeepSeek 接入、苏绣知识卡和体验意向记录等主要功能的前提下，解决以下实操问题：

1. 点击“婉娘导览”后页面自动滚到最底部，数字人形象与对话区不能同时看见；
2. 婉娘把知识范围限制在少量苏绣资料内，无法回答苏州景点、交通、美食和行程等文化礼宾问题；
3. 项目缺少稳定的一键启动入口，批处理文件曾出现闪退、端口漂移和生产/开发环境混用；
4. 快捷启动后出现“图片消失”的观感，需要判断是资源丢失、路径错误，还是运行环境与端口冲突。

---

## 二、问题诊断与关键决策

### 1. 页面自动滚动不是布局问题，而是滚动对象错误

原导览页在消息变化后调用 `scrollIntoView()` 定位底部占位元素。由于该元素属于整页文档流，浏览器会移动整个页面视口，导致进入导览页后直接看到输入框和页脚，数字人上半部分被滚出屏幕。

**决策：**取消页面级 `scrollIntoView()`，改为只控制右侧消息容器的 `scrollTop`，让聊天记录内部滚动，页面本身保持在顶部。

### 2. 数字礼宾不应等同于封闭式苏绣问答库

旧提示词要求模型只能依据项目资料回答，因此“苏州有什么景点”等合理住客问题会被生硬拒绝。酒店文化礼宾需要以苏绣为特色，但仍应具备苏州旅行通识和行程组织能力。

**决策：**采用“双层知识边界”：

- 涉及本课程原型、苏绣工艺和项目服务时，优先使用项目知识卡；
- 涉及苏州历史文化、景点、美食、交通、亲子旅行和住中规划时，允许 DeepSeek 使用通用知识；
- 对开放时间、门票、天气、展览、实时交通和餐厅状态等时效信息，明确提示以官方最新信息为准；
- 不声称具备实时联网检索能力，也不虚构项目已确认的价格、场次、容量、师资和材料。

### 3. “图片消失”实际是运行环境和端口管理问题

检查确认图片文件仍位于 `web/public`，直接请求均能返回。问题发生时存在多个 Vite 服务，端口由 5180 自动递增到 5181、5182，同时快捷脚本启动的是开发模式，与此前主要使用的生产预览模式不一致。

**决策：**快捷入口统一执行“生产构建 → 生产预览”，固定使用 5181，并通过 `--strictPort` 禁止静默切换端口。若生产预览已运行，再次双击只重新打开网页，不重复启动服务。

## 三、具体实现

### 1. 婉娘导览同屏布局与内部滚动

涉及文件：

- `web/src/pages/GuidePage.tsx`
- `web/src/index.css`

完成内容：

- 新增聊天滚动容器引用，消息更新后仅调用容器的 `scrollTo()`；
- 移除用于整页定位的底部引用和 `scrollIntoView()`；
- 桌面端采用左侧数字人、右侧对话区的固定视口高度双栏布局；
- 数字人资料区与聊天消息区内容过长时分别内部滚动；
- 移动端继续使用紧凑布局，避免照搬桌面固定高度。

### 2. DeepSeek 回答范围与检索逻辑重构

涉及文件：

- `web/vite.config.ts`
- `web/src/lib/llm.ts`
- `web/src/data/ichItems.ts`
- `web/src/pages/GuidePage.tsx`

完成内容：

- 重写中英文系统提示词，将苏州文化旅行与酒店礼宾问题纳入回答范围；
- 知识卡检索改为相关性评分，只在达到阈值时向模型提供项目卡片；
- 没有匹配项目资料时，不再机械附加前三张苏绣卡片，而是允许模型使用通用知识回答；
- 普通景点或行程问题不再错误触发“苏绣体验意向”操作卡；
- 更新中英文欢迎语、能力描述、输入提示和推荐问题；
- 保留史实、工艺经验、课程原型三类信息的边界说明。

### 3. 一键启动脚本重构

新增/修改文件：

- `一键启动网页.bat`

迭代过程：

1. 第一版通过批处理另开服务窗口、轮询端口后打开浏览器；
2. 实测发现 Windows `cmd` 在 UTF-8 中文批处理内执行 `goto` 时可能错误定位多字节字符，表现为命令被截断和终端闪退；
3. 将批处理内部命令和标签改为 ASCII，文件名仍保留中文；
4. 启动方式由 Vite 开发服务器调整为 `npm run build` 后运行生产预览；
5. 固定 `127.0.0.1:5181`，启用严格端口，避免悄悄切换到 5182；
6. 增加 Node.js、npm、依赖和构建失败检查，发生错误时保留窗口显示原因；
7. 检测到已有生产预览时，直接打开现有页面并退出当前启动器。

- 检查代码确认导览页不再存在 `scrollIntoView()` 和旧底部定位引用。

### 异常与 Plan B

浏览器自动化检查曾出现任务级 CDP 分发错误，无法直接生成页面截图。为避免把工具故障误判为项目故障，改用以下替代证据：

- 逐项请求静态资源并核对状态码、MIME 类型和字节数；
- 检查 5180—5182 的监听进程、启动命令和服务类型；
- 使用生产构建结果验证资源已正确复制到 `dist`；
- 人工实操时仍需补充页面同屏截图和实际问答录屏。

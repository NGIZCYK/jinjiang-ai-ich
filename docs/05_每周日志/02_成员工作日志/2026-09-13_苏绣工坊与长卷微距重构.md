## 一、改动背景与问题诊断（Why We Changed）

在前期测试与迭代反馈中，原“沉浸非遗角”暴露了四个深层次的问题，严重影响产品品质与课程评分表现：

| 痛点问题 | 根因诊断 | 劣势与评分风险 |
| :--- | :--- | :--- |
| **1. 3D/全景建模效果差、AI 虚假感与动漫感重** | 试图使用 WebXR / A-Frame 360° 全景甚至 AI 生成全景来构建空间。但受限于轻量级 Web 3D 渲染与生成模型的幻觉，画面呈现严重的平涂动漫感、线条形变与漂浮假物，**完全丧失了苏绣作为国家级非遗的“纯桑蚕丝微观经纬、丝光折射与劈丝走线”物理精髓**。 | 评阅人极易判定为“为技术而技术、为了 3D 而 3D”，不仅缺乏非遗真实感（Cultural Authenticity），而且带来廉价的 AI 玩具感。 |
| **2. 展品选材与首页重复** | 之前再次采用《花下双猫》作为主展项，与酒店首页已有的 5 幅苏绣主题画发生审美疲劳与内容撞车，缺乏宏大叙事与苏州地域文旅地标的结合。 | 内容叙事单薄，无法支撑锦江酒店“在地文化探索”的高端客群心智。 |
| **3. 微距镜算法 Bug、严重卡顿与初始遮挡** | ① 原微距镜使用 CSS `transform: translate(-X%, -Y%)`，导致局部坐标计算错位，滑移时极易滑出边界产生白屏；<br>② 鼠标移动高频触发 React 状态树 re-render，造成主线程掉帧、卡顿甚至假死；<br>③ **初始预先开启遮挡视野**：页面一打开正中间就浮着一个大圆镜，遮挡了长卷气势。 | 严重破坏用户体验，交互工程质量欠佳，在演示日或测试中存在崩溃风险。 |
| **4. 绣台图图省事共用单张图、步骤无直观物象** | 展位 03（试针）原本 4 个步骤共用 1 张模糊的静态图，点击步骤仅右侧文字变动，左侧画面毫无反应，且图片 AI 假图感重，缺乏上绷、配线、起针、装裱的真实器物支撑。 | 无法证明“非遗工坊住中体验”的实操闭环，削弱了产品商业落地的说服力。 |

## 二、今日改动内容与技术落地（What We Did）

### 1. 资产与场景范式转向：打造策展级《姑苏繁华图》数字典藏长卷

- **母本选材**：选用清代宫廷画师徐扬名作当代苏绣巨幅长卷《姑苏繁华图》（阊门水关至山塘繁华段），兼具**“大运河水系、商贸舟楫、古城水关、市井民俗”**四重文旅叙事。
- **真丝材质复合重制**：将高精图像与真实经纬织造纹理层（Silk Weave）及刺绣浮雕凹凸走线（Thread Relief）深度复合，彻底告别动漫画平涂感，呈现真实桑蚕丝绸的光泽质感。
- **4 处高光点位与经典针法解构**：
  - `01 阊门水关 · 巍峨城楼`：齐针 · 青砖垛口（平整如砌、沉凝厚重）；
  - `02 古石拱桥 · 市井人潮`：微雕开相 · 1/16 细丝（人物神态衣褶纤细如发）；
  - `03 万商泊舟 · 运河水纹`：水纹抢针 · 顺逆丝光（利用蚕丝三棱横截面折射活水波澜）；
  - `04 山塘市街 · 繁华商埠`：套针晕染 · 粉墙黛瓦（层层退晕、温润古雅）。

### 2. 微距镜算法底层重写与 60FPS 性能解放

- **绝对坐标实时平移算法**：
  将原本基于全局视口或相对偏移的粗略算法，重构为基于长卷容器（`imageContainerRef.current.getBoundingClientRect()`）的动态坐标矩阵计算。
  放大镜内高清纹理层（2.6x）完美咬合十字准星中心，彻底消灭空白与漂移。
- **原生 DOM Ref 直写，解耦 React 渲染流水线**：
  在 `handlePointerMove` 中直接操作 `loupeRef.current.style` 与 `loupeBgRef.current.style`，绕过 React 的 Virtual DOM Diff 计算，显著减少渲染开销，支持光标与触控拖拽。

### 3. 微距镜初始状态重构与三维智能唤醒

- **默认关闭保持视野开阔**：`loupeActive` 初始值设为 `false`，进入界面时主长卷一览无余；长卷右下角呈现呼吸微光引导标签：`“点击长卷或点位，开启 2.6x 丝痕微距镜”`；
- **顶栏主动控制**：按钮动态切换为 `🔍 开启微距镜 (2.6x)` 与 `✕ 收起微距镜`；
- **智能触发**：用户点击长卷任意位置，或点击 4 个图钉中任意一个，微距镜自动唤醒、激活并立即定位到目标坐标。

### 5. 展位 03（试针）多维双向联动体验

- **左侧视口动态切换**：大图随选中的步骤平滑更替，带有半透明毛玻璃工序浮层标签；
- **底部 4 步缩略图快捷切换条**：支持用户直接在左图底部点击 `01`、`02`、`03`、`04` 缩略图快速横向对比；
- **器物清单动态响应**：左下角器物说明根据选中的步骤实时切换对应专业工具要诀；
- **右侧步骤卡片内嵌缩略图**：每个步骤卡片左侧均配备 44×44 圆角实拍缩略图与完成勾选指示；

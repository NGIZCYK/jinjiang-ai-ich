# 2026-09-22 婉娘 Puppet 数字人：从静态背景板到可动数字人

## 背景与目标

`/guide` 页的婉娘此前只是单张静态 PNG，沦为"背景板"。真 Live2D 路线需要 ≥4096px 分层 PSD + 建模 + 授权，超出课程原型能力。本轮以 **2D puppet（分层部件偶动画）** 方案，接通任务书已铺好但视觉层从未消费的三条数据通道（口型 viseme、emotion、gesture），并首次消费 pace 字段，在零授权风险、零新 npm 依赖约束下让数字人真正"动起来"。

## 具体改动

### 1. 新形象与分层资产（AI 生成 + PIL 后处理）
- 按 `docs/07` 人设规范重新生成半写实国风立绘：墨玉绿改良旗袍制服、米白披肩、哑金苏绣胸针、低发髻、成熟温和；
- 生成嘴型五格（closed/a/aa/o/smile）与闭眼/半闭眼贴片差分图，`scripts/postprocess_avatar.py` 完成品红背景抠图、部件裁切、offset-only 肤色匹配（避免唇色失真）、边缘羽化、WebP 导出与锚点测量；
- 资产总量 **约 157KB**（任务书预算 ≤4MB），全部本地自持、无授权风险；
- 教训记录：首版均值/方差肤色迁移导致"小丑妆"失真、眉眼整片替换因眉-眼相对比例不一致产生双重眉——收敛为"单特征贴片"（只贴唇、只贴闭眼眼睑），睁眼表情用 base 原图。

### 2. 口型数据通道重构（消除每帧 React 重渲染）
- `useSpeechQueue.ts` 新增 `mouthSource` 订阅源：rAF 每帧只写 ref + 直推订阅者，旧 React state 降为 5Hz 节流兼容；
- `avatarTypes.ts` 新增 `MouthSource`、`AvatarPace`（自 `semanticPerformance.ts` 上移避免循环依赖）、`PuppetAvatarProps` 与舞台扩展字段。

### 3. PuppetAvatar 渲染器（`PuppetAvatar.tsx` + `puppetConfig.ts`）
- 分层 DOM：base 立绘 + 嘴部精灵（5 格）+ 双眼贴片（2 格，右眼镜像）+ 复用景深/微光层；
- **真口型**：`selectMouthCell(open, form)` 离散选格（圆唇/大张/展唇/微张/闭合）+ `scaleY` 连续微调，30ms 定时器滞回防抖（修复"语音停止后发布流中断导致嘴定格张开"的边界 bug）；
- **眨眼**：状态感知随机间隔（speaking 2~3.5s、idle 3~5s、thinking 5~7s），half→closed→open 90ms 序列；
- **状态微动**：speaking 点头、thinking 侧头、listening 前倾注视，全部克制在 ±1.5deg 内；
- **情绪**：warm 静默时自动切抿笑嘴格 + 暖光氛围、thoughtful 青光氛围；
- **手势**：introduce/acknowledge/emphasis 单次 CSS 动作，沿用 2.8s 自动复位；
- **pace**：`--puppet-pace-scale` 注入动画时基，lively 整体加快 15~20%；
- 口型/眨眼全程 ref 直写 DOM，**零 React 重渲染**；资产缺失或 prefers-reduced-motion 自动降级静态形象。

### 4. 集成与清理
- `AvatarStage` 三级调度：puppet（默认）→ 静态兜底（加载期间与失败时）→ Live2D（保留空管线不动）；
- `GuidePage` 透传 pace 与 mouthSource，静态兜底图换为同形象 poster.webp；
- 删除 `StaticAvatar` 无人消费的 `--avatar-mouth-*` CSS 变量写入与死代码 `avatar-speaking-cadence`。

## 验收结果

- `npm test -- --run`：**45/45 通过**（原 30 + puppet 新增 15：口型映射阈值、眨眼区间、滞回、锚点换算、精灵定位）；
- `npm run build`：0 错误，主包维持 433 KB（puppet 资产走 public 不进包）；
- 浏览器实测（CDP 注入采样）：
  - 待机 9s 内眨眼 2 次且自动复位；
  - 提问"介绍苏绣"→ emotion 正确推断为 thoughtful，gesture 2.8s 复位；
  - 朗读期间 6s 采样到 38 个连续 scaleY 值（0.898~0.945，对应 fallback viseme 0.16~0.32），嘴格稳定保持微张不抖动；
  - **Esc 打断后 300ms 内嘴闭合**、状态回 idle（修复滞回 bug 后复测通过）；
- 已知边界：验收环境页面不可见时 rAF 挂起导致口型暂停（浏览器标准行为，真实可见页面不受影响）。

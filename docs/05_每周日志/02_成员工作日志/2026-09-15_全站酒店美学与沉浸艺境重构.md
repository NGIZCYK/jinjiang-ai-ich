# 成员工作日志｜全站酒店美学与沉浸艺境重构

## 一、当日目标

在保留礼遇首页、婉娘礼宾、苏绣艺境、内容工作台、我的行程和分析看板等主要功能的前提下，借鉴高端酒店官网重视空间、在地文化和服务路径的设计方法，对网站进行两个阶段的整体改造：

1. 第一阶段统一全站品牌骨架、导航、色彩、字阶、卡片和按钮规则；
2. 第二阶段重点重构首页与沉浸非遗角，使“酒店住中体验”成为主叙事；
3. 减少通用后台、课程作业和功能堆叠的观感；
4. 提高苏绣文化内容的可读性，同时避免把数字原型包装成已经落地的真实酒店产品；
5. 保持中英文、桌面端与移动端体验一致。

本轮并未照搬某一酒店品牌的页面，而是提炼其共同方法：大幅空间影像、克制配色、充足留白、编辑式排版、少量明确行动入口，以及“空间—文化—服务”的连续叙事。

## 二、问题诊断与设计决策

### 1. 原页面功能齐全，但缺少统一的住客主线

旧首页同时展示项目定位、轮播作品、模块入口、体验信息和课程原型说明，信息价值相近却争夺同一视觉层级。用户能够看到功能，却不容易理解自己为何进入、将经历什么，以及各页面之间如何连接。

**决策：**将住客主线明确为“大堂观绣—客房识线—工坊试针—婉娘延伸服务”，让功能入口服务于体验章节，而不是以功能清单平铺。

### 2. 文化网站需要深度，但不能把解释压在场景上

沉浸非遗角已有长卷微距、丝线观察和绣台流程，但顶部状态、章节卡、热点提示、展签卡及底部说明同时出现，造成场景被界面包围。

**决策：**采用“场景优先、解释按需”的结构。主场景承担吸引和探索，展签放到独立侧栏，可随时收起；来源说明折叠保存，减少遮挡但不牺牲可信度。

### 3. 高级感不等于增加金色、阴影和装饰

原设计中部分圆角卡片、胶囊标签、阴影和小图标较多，容易形成通用 SaaS 界面感，与苏绣细腻、安静的文化气质不完全一致。

**决策：**以米纸白、烟墨、黛绿、旧木和低饱和暖金为主，使用细分隔线、宋体标题、现代正文、低圆角和小范围阴影建立层次，把视觉重点留给空间与作品。

### 4. 写实酒店图像必须明确其原型属性

本轮新增酒店大堂和主题房视觉图用于表达未来体验概念，但它们不是锦江真实门店摄影，也不代表相关空间已经建成。

**决策：**将图像作为课程原型中的 AI 辅助概念视觉使用；页面继续保留“文化礼宾原型”“数字创作、非馆藏复制”等说明，后续对外发布时必须进一步标注素材属性与授权状态。

## 三、第一阶段：全站品牌骨架与视觉系统

### 1. 导航从“功能菜单”转为“住客旅程”

- 住客主导航统一为“礼遇首页、婉娘礼宾、苏绣艺境、我的行程”；
- 内容工作台和分析看板保留为运营角色入口，不再与住客入口并列竞争；
- 桌面端使用居中导航、简洁语言切换和轻量账户操作；
- 移动端保留横向导航，控制信息密度并避免换行挤压；
- 页脚收拢为品牌、课程原型说明和苏州地点信息。

### 2. 建立“江南静奢”设计语言

- 更新米纸底色、烟墨正文、黛绿交互色、低饱和暖金和旧木色设计变量；
- 统一标题、正文、眉题、按钮、表单和卡片的字阶与边界；
- 减少大面积彩色按钮、过度圆角、重阴影与装饰性小图标；
- 使用细线、留白、材质感底色和编辑式排版建立视觉层次；
- 保留键盘焦点、跳到正文和减少动画偏好等可访问性支持。

### 3. 登录页与角色入口同步整理

- 登录注册页继承全站色彩与字体规则；
- 简化视觉装饰，突出登录动作、角色说明和演示入口；
- 保留本地鉴权与课程原型边界，不将演示账号包装为正式酒店会员系统。

## 四、第二阶段：首页住中叙事重构

### 1. 新建酒店大堂沉浸式首屏

首页首屏使用完整酒店空间影像，以“住进苏州，也住进一门手艺”为核心命题，并只保留两个首要行动：

- “遇见婉娘”：进入文化礼宾对话；
- “进入苏绣艺境”：进入数字工坊探索。

标题、说明和按钮放在画面暗部，苏绣艺术装置位于视觉中心右侧，使文字与空间互不遮挡。原有五幅苏绣作品不再承担首页第一视觉，而是移至后半段成为大堂策展内容。

### 2. 将功能入口改写为三段住客章节

首页增加三个连续章节：

| 章节 | 场景 | 对应功能 |
| :--- | :--- | :--- |
| 01 观绣 | 酒店大堂 | 打开《姑苏繁华图》数字纹理和微距点位 |
| 02 识线 | 苏绣主题房 | 查看蚕茧、劈丝、策展色样和丝光观察 |
| 03 试针 | 入门工坊 | 理解上绷、配线、起针与完成流程 |

每个章节可以通过查询参数直达沉浸页指定展区，例如：

- `/immersive?focus=artwork`
- `/immersive?focus=silk`
- `/immersive?focus=workbench`

### 3. 增加苏绣主题房空间叙事

- 新增主题房整幅视觉区域；
- 以苏绣绢屏、房内双语导览和工坊体验意向作为三个主要触点；
- 文案强调苏绣进入真实停留场景，而不是仅作为墙面装饰；
- 页面不承诺真实库存、固定房型、价格或已经上线的服务。

### 4. 强化婉娘在住客旅程中的角色

首页新增独立的文化礼宾段落，说明婉娘不仅介绍苏绣，也可以回答苏州文化旅行问题，并根据住客停留时间组织体验建议，使此前完成的 DeepSeek 能力扩展与首页叙事相连接。

### 5. 保留并降级五幅数字作品轮换

- 保留花下双猫、鹤与玉兰、莲池双鲤、海棠鸳鸯和紫藤翠鸟五幅作品；
- 将轮播移至页面下半部，作为“大堂轮换展陈”而非整站核心产品；
- 改为文字化上一幅、下一幅和 01—05 选择器；
- 支持鼠标停留和键盘聚焦时暂停自动轮换；
- 中英文统一标注为原型数字创作，不声称是馆藏复制。

## 五、第二阶段：苏绣艺境与交互层级重构

### 1. 页面改为“主场景＋可收放展签”

- 桌面宽屏下，工坊场景与展签并列，场景保持主要面积；
- 较窄屏幕下，展签自然排列到场景下方；
- 展签支持“收起展签”和“展开展签”；
- 切换观绣、识线、试针时，展签标题、正文、观察建议、住中延伸和来源说明同步更新。

### 2. 精简工坊顶部交互

- 将原有空间定位、状态胶囊、箭头和“正在探索”标签整合为紧凑标题栏；
- 三章入口只保留序号、章名和一句提示；
- 当前章节使用底部细线表达选中状态；
- 3x 微距镜按钮只在观绣章节出现，工序进度只在试针章节出现。

### 3. 降低热点对场景的遮挡

- 删除画面底部的悬浮操作提示；
- 移除热点持续闪烁动画和大范围金色外圈；
- 热点改为半透明深色小圆点，选中时才使用浅色和细金边；
- 保留编号、悬停名称、点击选择和微距定位能力。

### 4. 重写展签内容与文化边界

- “观绣”明确为参照《姑苏繁华图》公开著录城市风貌的数字纹理演绎；
- “识线”将蚕茧、劈丝、取色和丝光组织为材料观察序列；
- “试针”明确为入门课程的信息模型，不等于完整专业工艺规程；
- 五组色样标注为项目策展取色，劈丝等级标注为相对视觉比较；
- 来源与真实性说明保留在折叠展签中，减少视觉负担但便于复核。

### 5. 补充清晰的体验节奏

页面下方将 90 分钟原型体验拆分为：

- 观绣 15 分钟：选择一个微距点位并记录发现；
- 识线 20 分钟：比较材料、色样和相对细度；
- 试针 55 分钟：认识上绷与配线，并完成基础练习样片。

该节奏用于课程原型演示，师资、材料、场次与成品方式仍需合作方确认。

## 十一、追加改动：首页电影式视频素材流

### 1. 改动目标与设计取舍

在已完成的酒店品牌化视觉基础上，参考白马庄园网站首页的电影式开场节奏，将原有静态首屏重构为全屏视频素材流。借鉴重点是“全屏影像、透明导航、克制文案和少量核心操作”的信息组织方式，不复制对方的品牌标识、素材、预订组件或具体版式。

本次改动保留“遇见婉娘”和“进入苏绣艺境”两条原有核心路径，使视频承担氛围建立和文化引入功能，而不是取代项目的苏绣礼宾服务逻辑。

### 2. 输入素材与资产处理

| 资产 | 参数与处理结果 | 项目位置 |
| :--- | :--- | :--- |
| 用户提供视频 | 20 秒、1920 × 1080、25 fps、约 7.21 MB | 原文件保留于桌面，不直接依赖桌面路径 |
| 首页视频副本 | MP4，供浏览器本地加载和分段读取 | `web/public/videos/home-heritage-film-20260915-v1.mp4` |
| 首屏海报图 | 从视频前段提取，1600 × 900、约 38.2 KB，WebP | `web/public/assets/home-heritage-film-poster-20260915-v1.webp` |

处理原则：

- 将媒体复制到项目公共资源目录，确保项目压缩分享后仍能正常显示；
- 保留用户提供的原始视频，不覆盖、不裁切、不尝试移除原视频水印；

### 6. 内容真实性与版权边界

对视频关键帧检查后发现，素材包含央视网站水印，并混合出现水墨陈设、脸谱风格艺术、造像、灵长类动物和皮毛微距等画面。其中部分内容与苏绣及锦江酒店住中体验的直接关联较弱。

因此当前处理为：

- 仅将其作为课程高保真原型中的临时文化氛围素材；
- 不移除或遮盖现有水印，不暗示素材由项目团队原创；
- 不声称画面是锦江酒店实景、苏绣传承人工作现场或项目已落地服务；
- 页面保留“授权待复核”提示；
- 若用于公开展示、比赛或商业传播，应优先替换为来源清晰、无第三方水印、已获许可且内容聚焦苏绣工艺与江南酒店空间的影片。

## 3. 性能指标与工程质量审计

### 3.1 响应延迟与感知体验
- **首字反馈延迟**：提交后约 0.8~1.2 秒出现首个 token，思考期间舞台徽标与状态文本同步显示“思考中…”；
- **首句语音时延**：首个完整句子切分后，TTS 在 1.2~1.8 秒内启动音频合成并入队播放；
- **停止打断响应**：点击停止按钮或按下 `Escape`，AbortController 与 Web Audio 解码器在 `< 50ms` 内强制复位，无幽灵后台音频。

### 3.2 资源隔离与首屏体积（Bundle Budgeting）
生产构建（`npm run build`）产物分析：
```text
dist/index.html                                                   0.61 kB │ gzip:   0.44 kB
dist/assets/index-Gegq04A2.css                                  111.34 kB │ gzip:  20.54 kB
dist/assets/azureTts-Cf8u-6PT.js                                  2.54 kB │ gzip:   1.27 kB
dist/assets/index-e81kyQzY.js                                   341.09 kB │ gzip: 121.13 kB
dist/assets/microsoft.cognitiveservices.speech.sdk-D2x9_yep.js  380.98 kB │ gzip:  82.37 kB
✓ built in 1.70s
```
- **核心保障**：`microsoft.cognitiveservices.speech.sdk` 与 `azureTts` 采用动态按需导入（Dynamic Import），独立拆分为异步 chunk（380 kB），**对酒店首页首屏加载带来 0 字节体积负担**；
- **纯本地化资产**：数字人立绘、纹理与本地知识库均使用内部绝对/相对路径，不依赖任何不可靠的外部第三方 CDN。

### 3.3 内存与生命周期管理（Zero Memory Leak）
- **页面卸载清理**：离开 `/guide` 时，`useEffect` 清理钩子自动触发：
  - 终止正在进行的 SSE 流并回收 `ReadableStreamDefaultReader`；
  - 终止 Web Audio Context 并取消 `requestAnimationFrame` 口型时间轴循环；
  - 清理手势自动复位定时器 `window.clearTimeout`；
  - 移除全局键盘事件监听 `window.removeEventListener('keydown')`。

## 4. 无障碍（Accessibility & A11y）全面达标

1. **屏幕阅读器友好**：
   - 舞台状态容器配置 `aria-live="polite"` 与 `aria-label="婉娘：[当前状态]"`；
   - 思考、讲解、空闲、暂停等所有关键状态均同时具备**视觉高对比图标**与**明文字符提示**，严禁仅凭颜色辨别状态；
2. **键盘导航与快捷操作**：
   - 全局支持 `Escape` 快捷键极速打断生成与停播朗读；
   - 停止按钮显式标注 `aria-keyshortcuts="Escape"` 与 `title` 提示；
3. **减弱动效偏好（prefers-reduced-motion）**：
   - 在系统开启减弱动效时，自动平抑呼吸浮动、景深光晕缩放与颌部动效，仅保留必要的文本滚动与界面响应。

本文档记录 **2026-09-13** 针对 **阶段三（Phase 3）** 展开的系统级工程重构与美学体验落地。
在阶段一（非遗文博考据与微距真确性）和阶段二（业务状态机、意图路由与商业转化闭环）的基础上，阶段三聚焦于**品牌视觉质感、设计系统工程化（Design System）、80-15-5 黄金色彩配比与交互降噪**。彻底摆脱了早期原型的通用 SaaS 后台工具感与散乱杂糅的视觉符号，将全站升维为“文化策展 + 奢华文旅运营”兼备的高端数字文博产品。

## 一、阶段三核心改动背景与问题诊断（Why）

结合项目早期自测与《Codex优化建议.md》的专业诊断，原型在美学设计与体验系统方面暴露出以下核心痛点：

1. **色彩系统缺乏文化温度与品牌语义**：
   - 全站核心主按钮（`.btn-primary`）默认使用冷黑纯墨色（`#1c1917`），呈现出沉重、冰冷的现代工具软件风格，与“姑苏刺绣、温润真丝、江南水乡、奢华度假”的情境基调严重脱节；
   - 缺少全局统一的语义化色彩 Tokens，局部页面存在随意的饱和黄色渐变（`amber-300`、`amber-800`）、冷蓝色调与未受控的灰度阶梯，视觉语言支离破碎。
2. **字体与字阶层次欠缺东方文人调性**：
   - 全局界面以单一现代无衬线体通栏呈现，未能建立具有东方文人气息的字体体系；
   - 《姑苏繁华图》长卷展签、客房信笺、入席雅凭与金石印章未采用宋体/明朝体（Serif），缺乏文人书卷气与金石印鉴的庄重感。
3. **视觉层级存在结构性冗余与噪声**：
   - **沉浸非遗角页面双重导航冗余**：`ImmersivePage.tsx` 在长卷外部包裹了带有“当前展项”和“回到主长卷”的 `immersive-toolbar`，同时在长卷底部并列渲染了 `immersive-exhibit-tabs`，与长卷内置的常驻切换栏（01 观绣 / 02 识线 / 03 试针）形成**三重重复**，造成严重的视觉拥挤与操作干扰；
   - **混杂粗糙的 emoji 与符号系统**：页面中分散存在 `🔍`、`✕`、`◆`、`▶`、`★`、`✦`、`🖨` 等零散符号，在不同操作系统呈现样式参差不齐，严重削弱了高端酒店的克制与典雅。

## 二、具体技术落地与实现细节（What & How）

### 1. 五度色谱语义化 Tokens 与“80-15-5”黄金配比（`tailwind.config.js` & `index.css`）

我们在 `tailwind.config.js` 与 `index.css` 中建立了完整的苏绣传统五度色谱语义体系，并严格贯彻奢华界面设计的“80-15-5 黄金色彩配比法则”：

- **80% 底色与阅读基调**：
  - 古典米纸白（`paper: #faf7f2`、`paper-light: #fffdfa`、`paper-dark: #f4efe8`）模拟中国传统手工宣纸与生丝宣纸的温润质地；
  - 沉稳墨黛色（`ink: #1c1917`、`text-stone-700/800`）用于正文与深色对比；
- **15% 核心操作与激活色（姑苏水碧）**：
  - 提取苏州水网与清代设色画经典“水碧”（`jade: #2f6f5e`、`jade-dark: #1f4e42`、`jade-light: #eaf3f0`）；
  - 全站 `.btn-primary` 全面由生硬冷黑改为水碧色（`bg-jade text-white shadow-sm hover:bg-jade-dark`）；
  - 导航高亮态（`.nav-link-active`）、语言切换激活态（`.language-switch-active`）、步骤指示光环统一归一至水碧色；
- **5% 点睛微标与金石印鉴**：
  - **漆朱荷粉（`vermilion: #9e2a2b`、`vermilion-light: #fdf2f2`）**：严格对应文人书画印泥与火漆印章，应用于入席雅凭印鉴、信笺红印与紧急状态；
  - **金石暖金（`gold: #b08968`、`gold-light: #fcf7ef`、`gold-dark: #8c6b4f`）**：用于全站 `eyebrow` 顶栏小标（`tracking-[0.17em]`）、高光尊贵边框与丝线光泽；
  - **青黛沉稳（`slate.silk: #475569`）**：用于深色工艺参数与次级文字。

### 2. “宋体（明朝体）+ 现代黑体”双轨字阶系统

在 `tailwind.config.js` 中扩充跨平台的古典与现代双字体栈：
- `font-serif`: `"Songti SC", "Noto Serif SC", "Source Han Serif SC", STSong, SimSun, Georgia, serif`
- `font-sans`: `PingFang SC, "Hiragino Sans GB", "Microsoft YaHei", system-ui, -apple-system, sans-serif`

**应用规则**：
- **文人雅集层（Serif）**：`h1, h2, h3, .font-serif-title` 默认继承宋体美学，在《姑苏繁华图》主标题、展签大标题、客房信笺尊贵抬头、工坊入席雅凭中全面应用，营造如同翻开经典画册般的艺术享受；
- **信息参数层（Sans）**：微观线径数据（如 120μm、3.8μm）、时间分段（10:30、14:00）、操作按钮与后台分析图表保留现代无衬线体，保障高信息密度下的阅读清晰度与视认性。

### 3. 全站组件与交互降噪、符号标准化清洗

彻底清理散落全站的非标准符号与粗糙 emoji，统一为排版式微标与极简几何导向：
- **微距镜控制组件**：移除 `🔍` 与 `✕` emoji，改为精准的 `微距镜 · 开启` / `微距镜 · 收起` 排版状态按钮；
- **起针工序流程**：移除 `◆`、`▶`、`✦`，替换为极简线性实心圆点、`→` 导向符与宋体 `01/02/03/04` 工序徽标；
- **AI 对话与决策卡**：移除婉娘气泡与分析看板的 `★` 星号 emoji，统一设计为宋体篆刻“席”字印徽与“令”字决策徽章；
- **投影与边框收敛**：清除多层生硬的深黑阴影，统一采用超柔和微羽化投影（`shadow-xs: 0 1px 2px 0 rgba(0, 0, 0, 0.05)`）与极细暖调边框（`border-stone-200/80`、`border-gold/40`）。

### 4. 沉浸非遗角 (`ImmersivePage.tsx`) 视觉动线重构

- **剔除多余包裹层**：移除了外层重复的 `immersive-toolbar`（去掉了多余的“当前展项”和“回到主长卷”框）以及底部的 `immersive-exhibit-tabs`，消除了与组件内部顶部切换条的双重嵌套冲突；
- **确立单核心主舞台**：长卷与工坊场景组件（`LobbyConciergeScene`）直接作为大堂交互的核心展台呈现，清爽、大气、聚焦；
- **动线丝滑承接**：长卷下方紧接自适应更新的“展签解读卡片（Curatorial Label）”与“住客体验动线 / 今日推荐节奏 / 技艺说明”三栏卡片，构建起“**眼观长卷微距 -> 阅读文博考据 -> 规划住中体验**”的清晰认知序列。

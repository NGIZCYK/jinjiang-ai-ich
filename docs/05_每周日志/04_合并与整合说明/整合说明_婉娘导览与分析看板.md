## 配置说明

在 `web/.env`（勿提交）中配置：

```env
DEEPSEEK_API_KEY=你的密Seek密钥
DEEPSEEK_MODEL=deepseek-chat
DEEPSEEK_BASE_URL=https://api.deepseek.com
```

## 验收要点

1. `/guide` 左栏为视频数字人，而非「婉」字头像  
2. 待机 → 聆听（提问中）→ 讲解（开语音朗读）状态切换  
3. 左栏显示 DeepSeek 联网生成或本地规则知识库  
4. `http://127.0.0.1:5180/api/chat/status` 返回 `provider: deepseek|demo`  
5. 清空对话后恢复初始问候  
6. `npm run build` 通过

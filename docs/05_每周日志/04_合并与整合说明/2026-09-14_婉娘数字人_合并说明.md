# 将 2026-09-14 的婉娘导览更新合并到旧项目

适用场景：你将当前更新后的 `jinjiang-ai-ich` 打包成 ZIP 发给同学。同学需要把今天的婉娘数字人视频和 DeepSeek API 接入合并进自己的旧项目，同时保留其他成员已经完成的页面。

## 合并原则

不要用新 ZIP 直接覆盖旧项目的整个文件夹。应先解压到单独目录，例如 `jinjiang-ai-ich-20260914`，再只合并下表列出的文件。

合并前，同学应先备份自己的旧项目文件夹。对双方都改过的文件，使用 VS Code 的“比较所选内容”或合并编辑器逐段整合，尤其是 `GuidePage.tsx`、`llm.ts`、`vite.config.ts` 和 `index.css`。

## 推荐合并步骤

1. 解压新 ZIP 到独立文件夹，不能直接解压覆盖旧项目。
2. 备份旧项目。
3. 打开新旧两个项目文件夹，按上表逐个比较并合并文件。
4. 先复制 `web/public/images/` 中的三张婉娘状态图，以及 `web/public/videos/` 中的三段 MP4。这些文件没有代码冲突。
5. 合并 `GuidePage.tsx`：保留视频状态变量、`<video>` 标签、语音朗读结束事件和状态提示；聊天区、预约卡片等同学已有功能不能丢失。
6. 合并 `index.css`：只加入数字人舞台相关 CSS，避免整份覆盖。
7. 合并 `llm.ts` 和 `vite.config.ts`：确保前端只请求 `/api/chat`，不再直接请求 `https://api.deepseek.com`，也不再读取任何 `VITE_DEEPSEEK_API_KEY`。
8. 不要复制 `web/.env`。每位同学都应在自己电脑的 `web` 文件夹创建 `.env`，格式如下：

   ```env
   DEEPSEEK_API_KEY=自己的DeepSeek密钥
   DEEPSEEK_MODEL=deepseek-chat
   DEEPSEEK_BASE_URL=https://api.deepseek.com
   ```

9. 在合并后的 `web` 目录运行 `npm install`，随后运行 `npm run build`。
10. 启动 `web/start-dev.ps1`，访问 `http://127.0.0.1:5180/`，从首页进入“婉娘导览”。

## 验收清单

- 左栏显示婉娘视频，而不是“婉”字头像。
- 页面初始时播放待机视频。
- 发送问题时显示“正在聆听您的需求”，并播放聆听视频。
- 勾选“开启语音朗读”后，婉娘说话时播放讲解视频；朗读结束后回到待机视频。
- 页面显示“DeepSeek 联网生成”。
- `http://127.0.0.1:5180/api/chat/status` 返回 `{"provider":"deepseek"}`。
- 任意输入能得到 DeepSeek 的不同回答；关闭或移除 `.env` 后，页面仍可回退为本地演示回复。
- 浏览器开发者工具中不应出现 `VITE_DEEPSEEK_API_KEY`，也不应看到真实密钥。

## 常见问题

### 页面显示“本地规则知识库”

检查 `web/.env` 是否存在，变量名是否是 `DEEPSEEK_API_KEY`，填写后是否重启了 `start-dev.ps1`。

### `/api/chat/status` 返回 `demo`

说明 Vite 本地服务没有读取到密钥。检查 `.env` 是否位于 `web` 文件夹，且没有写成 `VITE_DEEPSEEK_API_KEY`。

### `/api/chat` 返回 502

检查网络、DeepSeek 密钥有效性和模型名称。`DEEPSEEK_MODEL=deepseek-chat` 是当前项目的默认配置。

### 数字人只显示静态图片或黑屏

检查三段 MP4 是否位于 `web/public/videos/`，并确认浏览器能访问 `/videos/wanniang-idle.mp4`。不要只复制图片而遗漏视频目录。

## 阅读入口

## 命名约定

| 前缀 | 含义 |
| :--- | :--- |
| `Week0X_` | Form 1 正式周报 |
| `2026-MM-DD_` | 按发生日期排序的过程日志 |
| `阶段二/三/四` | 全站重构阶段，日期相同属同一天多任务 |

## 使用建议

1. 提交 Form 1 时：从 `01_Form1周报` 出稿，用 `02_成员工作日志` 作附件证据。  
2. 核对组员贡献：对照 `03_组员交付日志` 与 `04_合并与整合说明`。  
3. 提交前阅读 [[00_采分对照与提交清单]]。  
4. 原项目根目录的 `log-*.md` / `Update-*.md` / `分析看板*.md` 为重复副本，已核对哈希一致后删除。

# Checkpoint 前优化与验收 · 2026-10-05

本轮已完成本地修改、100 项测试、TypeScript 检查和演示生产构建。保留现有 AI 聊天知识、提示词、模型、推荐解释与流式协议。**尚未发布到 GitHub、Netlify 或 Supabase**；当前执行环境没有发现云端发布凭据。

## 已实现

- 婉娘保留原脸及原素材。眨眼的所有定时器会在状态变化或离开页面时清理；暂停时恢复睁眼，停止微动。思考和讲解动作改为轻微、单次动作。继续禁用旧口型贴片。
- 默认关闭自动朗读。停止后立即清空队列，旧合成任务即使延迟返回，也不能恢复声音或覆盖新队列。离开导览页面同时取消生成和语音。
- 浏览器和 Azure 使用同一朗读文本处理，跳过 Markdown、代码和链接目标，保留“演示价格”“待确认”和括号内的服务限制。Azure 合成失败可回退浏览器语音；停止时释放音频、临时 URL 和合成器。
- “不喜欢”“不是很满意”归为负向；“喜欢但太贵”归为中性；“不太贵”不被误判为负向。看板明确标为“关键词表达倾向”，说明正向 / 中性 / 负向的表达条数，不能作为满意度或情绪判断。
- 只对运营简报请求启用 JSON 输出。前后端共同校验标题、决策、依据、行动、扩大门槛、暂停条件和限制说明。非法类型、缺失字段、过长字段、无效 JSON、截断结果均不被补成默认决策；失败提示重试，保留已有统计和已有简报。
- 语音和简报记录生成的请求编号、耗时、结果和固定错误类型，不记录聊天原文、操作员输入、令牌或原始错误详情。后台简报与语音令牌响应附带 `X-Request-Id`；聊天响应不增加这些日志。
- 前端版本由 v2 修正为 `2026.09.19-guide-v3`。网络失败和缺失版本元数据使用服务不可用提示，只有已知版本不兼容才提示刷新。

本轮不新增 Live2D 模型、口型素材、数据库表或聊天历史持久化，不修改权限策略、数据库人数计算、转化率计算或批次隔离。开始工作前已有的 ZIP 整合和启动脚本改动予以保留。

## 验收证据

| 检查 | 结果与范围 |
| --- | --- |
| 自动测试 | 7 个测试文件，共 100 项通过；包括原有数据库与业务测试 |
| 两名住客与运营权限 | 本地 PostgreSQL/PGlite 执行真实迁移及 RLS：住客互相隔离，运营不能读取私人导览记录，只能获取指定批次聚合统计 |
| 聚合准确性 | 两名正式测试住客预算 100 / 200，重复提交不重复计数，平均预算为 150；演示用户预算 900 被排除 |
| JSON 异常 | 模拟无效 JSON、缺失字段和截断结果，接口拒绝并显示可重试失败；不编造决策 |
| 语音故障 | 模拟 Azure 取消后无回调、延迟回调、音频播放受阻；任务正常结束并释放资源 |
| 浏览器队列竞态 | 旧请求 1 在取消后延迟返回，播放数量保持 0；新请求 2 正常播放，数量为 1；停止和卸载后为 0 |
| 人物状态与图片 | 思考 / 讲解 / 暂停正常切换；动态图片加载失败回退静态人物 |
| 真实浏览器朗读 | 成功播放浏览器语音；点击暂停后显示“已暂停”，日志记录 cancelled；离开并返回导览后仍默认关闭自动朗读 |
| 聊天回归 | 对照实施前备份：除关键词分类和版本元数据外，前端聊天文件一致；后台聊天消息、推荐解释提示和 SSE 生成代码一致；接口测试验证模型、温度、长度和 meta/delta/done 协议 |
| 构建 | TypeScript 检查、Vite `--mode demo` 生产构建通过；测试夹具不进入生产入口 |
| 云端只读版本核对 | 2026-10-05 课程演示环境公开接口返回 v3；不据此宣称新优化已部署 |

## 发布步骤

1. 由有项目权限的组员在 Supabase CLI 中登录并确认已连接**课程演示项目**，从项目根目录执行 `supabase functions deploy concierge`。包含 `supabase/functions/_shared/operatingBrief.ts`；本轮不要新建表、清空数据或重复执行 seed。现有模型、语音 Secrets 与来源配置保持原样。
2. 将本轮前端和函数代码一起提交、推送到现有 GitHub 项目，触发 Netlify 构建。仓库现有构建方式为 `npm run build:demo`，无需修改环境变量。若发布被锁定，先按现有项目设置解锁自动发布。
3. 打开新版 `/guide`，默认应为静音；开启或点播朗读，连续提问、停止、切换页面，确认没有残留声音。
4. 用两名住客分别提交带“苏绣”“预算”的不同需求，再用运营账号读取同一测试批次。住客之间不可读取私人记录，Demo / Study 01 不混合，聚合人数去重。
5. 运营简报失败时核对错误提示和请求编号，确认原统计保留。不要把聊天原文、认证令牌或模型密钥粘贴到日志或课程报告。

本地复核命令（在 `web` 目录）：

```powershell
npm test
npm run build:demo
```

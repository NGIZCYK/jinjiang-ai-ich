## 2. 改造清单（按优先级）

### P0-1 压缩首页三张主视觉（性能）

**问题：** `public/assets/suxiu-*.png` 单张约 3MB，首屏过重，易被误判为「打不开/很卡」。

**要求：**

1. 将三张图转为 WebP（或先 PNG 再 WebP）。  
2. 长边约 1400–1600px，单张目标 **≤ 350KB**（尽量 ≤ 250KB）。  
3. 更新引用：`PremiumHomePage.tsx` 中 `artworks[].src` 改为 `/assets/suxiu-*.webp`。  
4. `<img>` 增加：
   - 非首张 `loading="lazy"`
   - 明确 `width`/`height` 或 CSS `aspect-ratio`，减少 CLS
   - 失败时显示占位块（可选）

**验收：** DevTools Network 中三图总传输明显下降；首页无 404。

---

### P0-2 A-Frame 本地化 + 加载回退（演示稳定）

**问题：** `index.html` 使用 `https://aframe.io/releases/1.5.0/aframe.min.js`，无网/墙环境大堂场景会挂。

**要求：**

1. 将 `aframe.min.js` 放到 `web/public/vendor/aframe.min.js`（可用当前已验证版本 1.5.0）。  
2. `index.html` 改为本地：`<script src="/vendor/aframe.min.js"></script>`。  
3. `ImmersivePage` 增加加载态/失败态：
   - 场景容器显示「正在加载苏绣文化礼宾大堂…」
   - 若 `window.AFRAME` 在超时后仍不存在，显示 2D 展签回退说明（页面下方已有展签内容，保留即可）

**验收：** 断网（或屏蔽 CDN）后刷新 `/immersive`，场景仍可加载或明确回退，不出现无说明黑屏。

---

### P0-3 内容工作台：表单真正参与生成（核心功能闭环）

**问题：** `StudioPage.tsx` 中「目标住客 / 触达渠道 / 可用时间 / 传播场景」未传入生成函数，属于 UI 装饰。

**要求：**

1. 用 `useState` 管理：
   - `audience`（目标住客）
   - `channel`（触达渠道）
   - `prefer` / `time`（行程）
   - `scene`（文案场景）
2. 修改 `src/lib/llm.ts`：
   - `generateItinerary(prefer, language, options?: { audience?: string; channel?: string })`
   - `generateMarketingCopy(scene, language, options?: { audience?: string; channel?: string })`
3. 生成结果中**必须回显**这些变量，例如：
   - 「目标住客：亲子文化体验住客」
   - 「触达渠道：大堂礼宾屏」
   - 「可用时间：2 小时」
4. 保存到「我的体验」时，标题可包含 audience/channel，便于评审识别闭环。
5. 若后续接 DeepSeek，同样把上述字段写入 user prompt。

**验收：** 修改任一表单项后生成，正文出现对应字段；换字段再生成，内容有差异。

### P0-4 导览 TTS 语言与中英默认值同步

**文件：** `GuidePage.tsx`、`StudioPage.tsx`、`MyPage.tsx`

**要求：**

1. TTS：`u.lang = language === 'zh' ? 'zh-CN' : 'en-US'`。  
2. `StudioPage` 切换语言时，重置/同步：
   - `prefer`（如 `2 小时` / `2 hours`）
   - `scene`（如 `周末微度假` / `Weekend escape`）
3. `MyPage` 切换语言时，保证 slot 下拉与默认选中项语言一致（已有部分逻辑，补齐即可）。

**验收：** EN 模式下朗读为英文；切语言后输入框/下拉不残留上一语言默认值。

### P1-1 大堂场景与首页视觉统一

**文件：** `LobbyConciergeScene.tsx`、`ImmersivePage.tsx`、`textures.ts`

**要求：**

1. 大堂**主展画**优先使用首页同源图（压缩后的 `suxiu-cats-lobby-art.webp`）作为贴图，而不是仅用程序色块。  
2. 工艺柜/丝线色谱、礼宾屏与主画色板统一：墨绿 / 暖金 / 米白 / 深木色。  
3. 确保展品与热点坐标不重叠；热点贴附在实物附近，不要漂浮在空地。  
4. 灯光保持明亮酒店大堂感（避免过暗）。

**验收：** 首页与 `/immersive` 主画题材一致；热点可点；无明显穿模/重叠。

### P1-2 分析看板英文映射改为稳定结构

**要求：**

1. `AnalyticsSnapshot` 扩展字段（向后兼容）：

2. 页面按 `language` 选择 `name` 或 `nameEn`，禁止依赖 index 映射。  
3. 若同步改 Python，输出 JSON 带上 `name_en`；前端 mock 与之一致。

**验收：** 切换 EN，客群/情景/ROI 名称正确且不串位。

## 7. 给执行 AI 的工程约定

1. 优先改现有文件，避免平行再造一套页面。  
2. 保持 TypeScript strict 可通过；不要用大量 `any` 掩盖问题。  
3. 样式继续用现有 Tailwind 语义 token（`jade` / `silk` / `gold` / `paper` / `ink` 等，见 `tailwind.config.js` 与 `index.css`）。  
4. 文案保持学术/酒店礼宾语气，不用 emoji。  
5. 每完成一个 P0，可先构建一次，避免一次性大爆炸改动。  
6. 若必须新增依赖，仅允许轻量库；A-Frame 本地文件不算新依赖。

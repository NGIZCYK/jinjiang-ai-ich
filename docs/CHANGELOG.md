## [2026-09-22 婉娘 Puppet 数字人] 分层偶动画接通口型/情绪/手势/节奏四条表演通道

### 1. 改动原因（Why）
- **数字人沦为"静态背景板"**：`/guide` 页婉娘仅渲染单张 PNG，任务书铺设的口型（viseme）、emotion、gesture 三条数据通道在视觉层零消费，pace 字段产出即丢弃；
- **真 Live2D 超出课程能力**：需 ≥4096px 分层 PSD + 建模 + 授权；转而以 AI 生成 + PIL 后处理自产分层部件，做 2D puppet 偶动画，零授权风险、零新 npm 依赖。

### 2. 具体改动内容（What）
- **【新形象与分层资产】**：按 docs/07 人设生成半写实国风立绘（墨玉绿旗袍制服、低发髻）；嘴型五格精灵 + 闭眼/半闭眼贴片；`scripts/postprocess_avatar.py` 完成抠图、裁切、offset-only 肤色匹配、羽化、WebP 与锚点输出；资产总量约 157KB（预算 ≤4MB）；
- **【口型通道重构 (`useSpeechQueue.ts`)】**：新增 `mouthSource` 订阅源，rAF 每帧直推订阅者，React state 降 5Hz 节流，消除说话期间每帧重渲染；
- **【PuppetAvatar 渲染器（新建 `PuppetAvatar.tsx` / `puppetConfig.ts`）】**：
  - 真口型：`selectMouthCell(open, form)` 五格离散选格 + scaleY 连续微调 + 30ms 定时器滞回防抖；
  - 眨眼：状态感知随机间隔（speaking 更频、thinking 更稀）的 half→closed→open 序列；
  - 状态微动：speaking 点头 / thinking 侧头 / listening 前倾，克制在 ±1.5deg；
  - 情绪：warm 静默自动抿笑 + 暖光、thoughtful 青光氛围；手势单次动作沿用 2.8s 复位；pace 经 `--puppet-pace-scale` 首次接入动画时基；
  - 口型与眨眼全程 ref 直写 DOM，零 React 重渲染；资产缺失或 prefers-reduced-motion 自动降级静态形象；
- **【集成与清理】**：`AvatarStage` 三级调度（puppet → 静态兜底 → Live2D 空管线不动）；`GuidePage` 透传 pace/mouthSource，兜底图换为同形象 poster.webp；删除 `StaticAvatar` 无效 `--avatar-mouth-*` 写入与死代码 `avatar-speaking-cadence`；
- **【当场修复】**：滞回逻辑在语音停止后发布流中断导致嘴定格张开——改为定时器滞回，Esc 打断 300ms 内闭嘴。

### 3. 验收结果
- `npm test -- --run`：**45/45 通过**（原 30 + 新增 15 项 puppet 单测）；
- `npm run build`：0 错误，入口主包维持约 433 KB；
- 浏览器 CDP 注入采样实测：眨眼定时触发并复位；craft 问题 emotion=thoughtful 且 gesture 2.8s 复位；朗读 6s 内 38 个连续 scaleY 值、嘴格稳定不抖；Esc 打断闭嘴回 idle；reduced-motion 双保险降级。

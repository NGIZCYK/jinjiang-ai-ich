# 产品需求说明（原型版）

## 背景

锦江杯「智创非遗，焕活文旅」要求：生成式 AI × 非遗 × 酒店/文旅业务，并含商业分析层。本原型聚焦**酒店运营**场景，以**苏绣**为内容主轴。

## 用户

- C 端：酒店住客 / 预订兴趣用户  
- B 端演示视角：酒店市场与运营（分析看板）

## 用户故事

1. 作为住客，我希望与数字人婉娘对话，快速了解苏绣故事与可体验活动。  
2. 作为住客，我希望浏览沉浸非遗角，并生成 2 小时体验行程与分享文案。  
3. 作为住客，我希望预约苏绣体验课并管理预约。  
4. 作为运营，我希望看到客群分层、有/无非遗模块的收入情景与 ROI 建议。

## 范围

**做**：鉴权、导览对话、A-Frame 角、行程/文案生成、预约、情感标签、分析看板、演示数据。  
**不做**：真实 PMS、支付、Unity 3D、多物业权限。

## 验收（课程对齐）

- 至少 5 个独立屏幕，导航连贯  
- 3 个具备业务闭环的核心功能  
- 真实注册登录（本地或 Supabase）  
- 可公开部署访问链接  
- Demo 可完成：输入 → 处理 → 预约/生成 → 看板结论

## 本地预览

地址：<http://127.0.0.1:5182/immersive>。

在 `web` 目录、使用项目配套 Node 24.22.1 运行 `npm run dev:atelier-preview`。该命令使用 `atelier-preview` 模式和独立端口5182，不影响其他开发服务。

此模式即使存在 Supabase 环境配置也不会创建云端客户端。探索卡无需登录，草稿和保存结果使用独立的 sessionStorage 键，不覆盖原有 `jj_v2_exploration_draft`；刷新可恢复，标签页会话结束后清除。此模式只供本地视觉与交互审阅。

## 已完成

- 观绣改用已确认的1080×1880浅紫花卉苏绣照片，电脑完整竖图不超过640px高；可用空间充足时右侧显示独立细节窗，窄屏上下排列。
- 四个观察点为粉瓣晕色、白瓣明暗、花蕊细节和背景线向。点位、点击全图、方向键微调及Home返回使用同一原图坐标；边缘裁切受约束。
- 细节窗使用同一原图的400×400区域，显示宽度不超过360px；不使用另外生成的微距照片，不添加针脚或宣称显微精度。自由观察不自动推断探索卡主题，选择命名点位才记录主题。
- 取色经后续四图审核，改用 Lansei China 淡彩丝线木托盘照片，保留五组数字配色、线束及探索卡映射；之前的 Jim Thompson House 照片保留在素材记录中，已不用于取色展位。
- 用户确认：蚕茧用新木碗实拍；劈丝保留原先绿色底布的AI概念图；取色用新淡彩木托盘实拍；丝光将已展示的皇家刺绣学院花卉课程图接入本地试用，四图整体协调性仍待用户审核。四张以3:2画框展示，取色采用审核对照中的偏下方构图，原图不改色。
- 丝光改为“以线塑形”，用“看线向／看色阶／看层次”三个同图局部，说明随形排线、明暗色阶与前后叠压怎样共同呈现花瓣的立体感。移除此前模拟线束受光的三个按钮；取色的色卡与线束预览、劈丝及试针功能保留。
- 相关展签、中英文提示及本地推荐说明与新观绣行为一致。
- 新花卉主题使用独立标识；旧城楼、古桥、运河和市街的标识与文字含义保留，进度校验和后台显示同时支持两组标识。

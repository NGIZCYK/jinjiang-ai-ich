## 产品一句话

## 三大核心功能

1. **非遗智能导览**：苏绣故事问答、工艺讲解、体验推荐  
2. **沉浸角 + 内容生成**：A-Frame 苏绣角 + 个性化行程/营销文案  
3. **预约与转化分析**：体验课预约落库 + 客群/收入/ROI 看板  

基础设施：注册登录、我的足迹、内容工作台。

## 开发原则

- 无在线模型时仍可完成探索和规则推荐；共享保存需要 Supabase  
- DeepSeek 密钥仅配置在 Supabase Edge Function，前端不读取模型密钥  
- 分析脚本可独立运行，结果 JSON 回填前端看板  
- 不写入 ENT207 Obsidian 知识库

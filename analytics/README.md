# 分析重算

当前模型使用 1,200 条随机种子为 42 的合成样本，不代表真人测试或酒店经营数据。

从项目根目录执行 `./analytics/recompute.ps1 -InstallDependencies`，首次将锁定依赖安装到项目缓存；之后执行 `./analytics/recompute.ps1`。不会修改系统 Python 包。当前锁定版本在 Windows x64 / CPython 3.14 验证，详见 `requirements.txt`。

输入唯一来源为 `shared/roi-assumptions.json`，前端 `web/src/lib/roi.ts` 和 Python `roi.py` 均读取此文件。金额统一为人民币元，收益、成本按月计算；净 ROI =（月贡献 × 12 − 启动投入）÷ 启动投入 × 100%，回收期 = 启动投入 ÷ 正月贡献。无投入时 ROI、回收期为空；亏损时回收期为空。此模型不含税、折现、折旧。筛选比例只改变工坊需求，客房溢价仍以全酒店月收入为基数。

重算先运行分析回归测试，再同时写入 `analytics/output` 与 `web/public/analytics`。生成时间会更新，样本在同一依赖版本下可复算。历史 74.7% / 11 个月快照属于旧口径，不能与当前 272.8% / 3.22 个月结果混用。

前端回归测试另验证两个实现对默认、筛选、零投入、亏损及异常范围输入逐字段一致。经营扩大还需要 Study 01 真人核验、连续四周真实转化与到课证据，以及人工复核；当前数字流程统计不自动满足这些条件。

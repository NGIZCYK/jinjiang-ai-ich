## 先提供预览小样，无需立即购买

平台详情有“下载小样”入口。先将带水印的小样保存到本文件夹下的 `input/`，用于选片与剪辑预览。文件可保留原名，或命名为：

1. `01-main-preview.mp4`：https://www.vjshi.com/watch/35987610.html
2. `02-detail-preview.mp4`：https://www.vjshi.com/watch/26609340.html

文件名不限；用户提供实际路径后继续检查。带水印小样仅用于审片，不作为最终首页素材。

抽帧命令（在项目根目录运行；文件路径按实际下载名称替换）：

```powershell
python scripts\inspect-hero-source.py assets-source\hero-film-20261030\input\01-main-preview.mp4 --output .cache\hero-film-20261030\review-01
python scripts\inspect-hero-source.py assets-source\hero-film-20261030\input\02-detail-preview.mp4 --output .cache\hero-film-20261030\review-02
```

每个素材输出接触表与 JSON，记录原始文件 SHA-256、尺寸、帧率、估算时长和采样时间。原文件保持不变；时间精度以最终剪辑时逐帧核对为准。

## 原片与最终输出

初剪确认后，使用平台授权提供的无水印原片替换小样，逐段核对起止位置、帧率与裁切，再导出网页使用的横版和手机适配版本。原片不可用时不声称完成无水印成片。

审片重点：真实丝光与落针细节、统一的暖灰与黛青色调、左侧标题留白、缓慢稳定的镜头、自然循环衔接。保留静态海报回退、暂停控制和减少动态效果偏好。

检查最终文件的尺寸、时长、帧率、完整解码、循环接点与文字覆盖效果后，才接入本地首页并更新改动日志。本轮不发布云端。
